# NSVL logo assets

Four transparent PNG reconstructions of the selected identity: standalone NSVL and NSVL / NASHVILLE lockup, each in Charcoal Ink and Paper White color directions.

These were reconstructed from the supplied raster concept using the built-in image-generation tool. They are not original vector masters or mathematically identical color swaps. Minor shape and color differences can exist. Use for design review and implementation prototyping; obtain/approve a single vector master before final production, large print or embroidery. Do not turn an embedded PNG into an SVG and claim it is vector artwork.

## Application
- Desktop header/footer: full lockup, starting at 140px visible artwork width.
- Mobile header: standalone mark, starting at 88px visible artwork width. Preserve aspect ratio and allow clear space; note the files contain transparent margins.
- Light backgrounds: charcoal.
- Dark backgrounds: paper white.
- Apparel: one-color mark; vendor must work from the approved vector and run physical samples.

## Remaining production exports
The original vector, exact flat-color exports from a single master, pure black/white print variants, and a separately approved small-size favicon remain outstanding. A wide wordmark is not a legible 16px favicon. No replacement monogram has been invented here.

## Generation prompt summary
Input: references/selected-source.png, top-center header logo.
Request: isolate the exact connected angular NSVL mark; preserve geometry; full lockup includes widely tracked NASHVILLE beneath; standalone omits descriptor; transparent background, one flat brand color, no shadows/textures/extra imagery. Paper-white corrections use the charcoal assets as references and request color-only changes with clean transparent negative space.

## White PNG quality
Paper-white raster exports retain edge/negative-space artifacts and are labeled review-only. Do not ship them. For web prototypes use logo-preview.html: its CSS mask renders the charcoal silhouette in exact flat brand colors without relying on the white exports. Final clean raster exports should come from the single approved vector master.
